# Personalized Chess Learning Engine

> Aspect 7 of the menu. Strong differentiation.

Chess Coach AI must gradually learn the user's playing style and weaknesses.

Study and develop a personalised learning system.

The application must analyse the history of games and identify:

- Recurring tactical errors.
- Pieces regularly left hanging.
- Missed tactical motifs.
- Poor positional decisions.
- Weaknesses in the opening.
- Difficulties in the endgame.
- Calculation errors.
- Missed winning chances.
- Bad playing habits.

Build a dynamic player profile.

From this profile, the application must be able to recommend personalised
exercises automatically.

Example: if the player regularly misses knight forks, the system must identify
this weakness and offer more exercises on this theme.

Study spaced repetition, FSRS, Leitner and personalised teaching approaches.

Do not just build a statistics dashboard.

The goal is a real engine that decides what the player should learn next.

Implement the relevant improvements, with tests.
