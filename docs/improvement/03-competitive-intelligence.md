# Competitive Intelligence — Chess.com vs Lichess vs chessed

> Aspect 4 of the menu.

Run a new, in-depth competitive study.

Analyse the latest features of Chess.com, Lichess and the best chess analysis
applications.

Look for:

- New features.
- Engine improvements.
- New classification systems.
- Teaching features.
- New GitHub projects.
- New libraries.
- Innovations in AI explanations.
- Performance optimisations.

Compare these features with our current code.

For each interesting feature, state:

- What it brings.
- How it works.
- Whether it is technically feasible in our architecture.
- Its value for our user.
- Its development cost.
- Its priority.

Do not copy competitors blindly.

Also identify the features that could give us a real teaching advantage.

Implement the relevant improvements and update the documentation.
